# Prompt — implementar uma mudança aprovada

Leia AGENTS.md e Skills relevantes. Implemente somente a mudança explicitamente aprovada. Antes de editar, confirme escopo, arquivos afetados, contratos preservados, riscos e testes. Faça a menor alteração reversível possível. Não modifique funcionalidades não relacionadas. Execute verificações disponíveis e relate exatamente o que foi executado e o que não foi possível validar.
