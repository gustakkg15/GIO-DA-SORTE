# Checklist de release

- [ ] Escopo e diff revisados.
- [ ] Nenhum segredo ou dado sensível incluído no bundle/log.
- [ ] Migrações revisadas e não destrutivas.
- [ ] Backup/rollback definido quando houver mudança de dados.
- [ ] Lint/typecheck/testes/build executados quando disponíveis.
- [ ] Fluxos críticos afetados testados.
- [ ] Permissões verificadas no servidor.
- [ ] Mobile/desktop verificados quando houver UI.
- [ ] Monitoramento/logs sem dados sensíveis.
- [ ] Limitações e riscos documentados.
- [ ] Aprovação explícita antes de publicar em produção.
